# Dados

O arquivo `world-happiness-report-2019.csv` é o CSV usado nesta análise.

Fonte indicada: [World Happiness Report — Kaggle](https://www.kaggle.com/promptcloud/datasets).

Se o CSV não estiver presente, baixe `2019.csv` na página do dataset e coloque-o nesta pasta, renomeando-o para `world-happiness-report-2019.csv`. Confira os termos/licença do Kaggle antes de redistribuir o arquivo.

Atenção: o arquivo analisado neste projeto contém a coluna `Ladder` (ranking) e não a pontuação `Score` de 0 a 10.
